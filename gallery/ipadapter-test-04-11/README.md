# IP-Adapter — העברת זהות מרפרנס (04/11/2026)

## השאלה
אחרי שסגרתי את מסלול ה-LoRA (12 קונפיגורציות, אפס עוברות), נשאר המסלול המומלץ: קונדישנינג ברפרנס.
המבחן: IP-Adapter + SDXL, רפרנס = חיתוך פנים אמיתי של רוני, פרומפטים של סצנות שלמות.

## התובנה שמשנה את שער הקבלה
כל הניסיונות עד כה בדקו **העברת זהות** לדמות חדשה בסצנה חדשה — וזה נכשל בכל שיטה (LoRA, דיסטילציה, IP-Adapter).
אבל יש לנו מספר אחר לגמרי שעמד כל הזמן לנגד עינינו: **העקביות הפנימית של סטים שהצינור שלנו ייצר היא 0.542** (רוני, 45 פריימים; ספיר 0.587).
כלומר הצינור שלנו **כן** מפיק דמות עקבית, כשהיא נוצרת באותה סדרת הפקה עם אותם תנאים — וזה בדיוק מה שסט קאנון הוא.
