- 58 סוכנים אוטונומיים, 6 תחומים — מהתיאור בריפו המוצר.
- `POST /create-payment-link` → עמוד checkout דינמי → PayPal webhook כאימות היחיד → PaymentRecord → היפוך אובייקט עסקי → לדג'ר עמלות. הכל מהחוזה המתועד בריפו.
