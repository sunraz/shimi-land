שימי פיט

אימוני ישבן חכמים, הדמיה אישית של היעד, טבלת ייאוש ושידור מיקום לווידג׳. שני מסלולי התקנה לאייפון.
הכי מהיר · עובד עכשיו

1. התקנה כמסך בית

שתי לחיצות, בלי מחשב, בלי חתימה. האפליקציה נפתחת במסך מלא עם אייקון משלה.

הורד את פרופיל ההתקנה
  1. לוחצים על הכפתור, ספארי מוריד את הפרופיל.
  2. Settings, ואז „Profile Downloaded”, ואז Install (יקלידו קוד נעילה).
  3. אייקון „שימי פיט” מופיע במסך הבית. פותחים ומאשרים מיקום.
במסלול הזה השידור רץ כשהאפליקציה פתוחה. שידור ברקע דורש את האפליקציה החתומה שבהמשך.
אפליקציה מלאה · IPA

2. אפליקציית iOS

אפליקציה מקורית עם שידור מיקום ברקע, קריינית עברית מקומית והתראות. הקובץ בנוי ומוכן.

הורד את ShimiFit-1.0.ipa

אפל דורשת שכל אפליקציה תיחתם בחשבון מפתח. שתי דרכים:

  • Sideloadly במחשב: גוררים את ה-IPA, מזינים Apple ID חינמי, והוא חותם ומתקין דרך הכבל. תקף 7 ימים ואז חותמים שוב.
  • חשבון מפתח בתשלום: חתימה לשנה שלמה, וגם שידור רקע ללא הגבלה.
אם שולחים לסאן קובץ p12 ו-mobileprovision, החתימה נעשית ישירות אצלנו והקובץ מותקן בלי מחשב.

מה יש בפנים

  • תוכנית ישבן ב-4 רמות, נפרדת לגברים ולנשים
  • 14 תרגילים עם הדגמה מונפשת של המדריכה בלבוש הקנוני
  • קריינית עברית, ספירת חזרות, מנוחות ופומודורו
  • צילום גוף, מדידת מבנה גוף, וסליידר חי 1–4 על התמונה שלך
  • טבלת ייאוש חיה מהשרת, ושידור מיקום לווידג׳
