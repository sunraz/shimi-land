# מדד זהות פנים — כלי בדיקה לפני אימון (03/11/2026, שימי פיתוח)

## הבעיה שזה פותר
אימנתי LoRA לליילה שלוש פעמים וקיבלתי תוצאות חלשות. השאלה הייתה אם הבעיה בצינור או בחומר.
בלי מדד אמין אין תשובה. הקורלציה הגרייאית שהשתמשתי בה עד היום רועשת מדי.

## הכלי
`identity_metric.py` — זיהוי פנים (YuNet) → יישור 5 נקודות (similarity transform ל-112x112) → embedding (ArcFace w600k_mbf) → cosine.
רץ על CPU בלבד, בלי GPU. שימוש:
```
python identity_metric.py baseline <DIR>                  # עקביות פנימית של סט
python identity_metric.py compare <REFDIR> <sample...>     # דמיון דגימות לסט ייחוס
```
רפי החלטה: פנים עם ביטחון <0.75 או רוחב <80px נפסלים (מונע זיהויי שווא שמזהמים את הבסיס).
